# Steam Chat Viewer

Просмотр всей истории переписки из Steam в виде обычного мессенджера.

Steam не хранит историю чатов на компьютере: её можно получить только со страницы
[«Журнал сообщений»](https://help.steampowered.com/ru/accountdata/GetFriendMessagesLog) в данных аккаунта.
Там она выглядит как огромная таблица. Это приложение превращает её в удобные чаты.

## Возможности

- список собеседников с последним сообщением и числом сообщений;
- переписка пузырями с разбивкой по дням;
- смайлики, стикеры и ссылки Steam отображаются читаемо;
- поиск по собеседникам, по всем сообщениям и внутри чата;
- экспорт переписки с одним человеком в `.txt`;
- темы оформления: 6 готовых (Steam, Светлая, Графит, AMOLED, Фиолетовая, Лес) и редактор своей темы
  с предпросмотром; темами можно делиться через JSON (кнопка 🎨).

## Как пользоваться

1. Откройте страницу GitHub Pages этого репозитория или скачайте репозиторий (Code → Download ZIP) и откройте `index.html`.
2. Перетащите кнопку **«📥 Steam → история чатов»** на панель закладок.
3. Откройте журнал сообщений Steam, войдите в аккаунт и нажмите закладку:
   она сама подгрузит всю историю и скачает файл `steam-chat-ДАТА.html`.
4. Перетащите скачанный файл в приложение.

## Расширение для браузера (Chrome, Edge)

Расширение загружает историю само, без закладок и файлов: одна кнопка «Обновить историю»,
а по желанию — автообновление раз в день.

**Установка:**
1. Скачайте репозиторий: **Code → Download ZIP** — и распакуйте.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку (ту, где лежит `manifest.json`).

**Использование:** нажмите значок расширения → «Обновить историю», затем «Открыть историю».
Если вы не вошли в Steam, откроется вкладка Steam — войдите в ней сами и нажмите «Обновить» ещё раз.

**Разрешения:** доступ только к `help.steampowered.com` (чтобы прочитать журнал сообщений),
хранение данных в браузере, фоновые вкладки и таймер для автообновления.
Автообновление выключено, пока вы сами не поставите галочку.

## Конфиденциальность

Всё работает локально в браузере: файл с перепиской никуда не отправляется и не сохраняется.
Закладка и расширение выгружают только таблицу сообщений, без служебного кода страницы и данных сессии.
Расширение не знает вашего пароля и не трогает cookies — оно просто открывает страницу Steam, в которую вы уже вошли.
