Steam Chat Viewer

Удобный просмотр истории переписки из Steam. Всё работает локально, файл никуда не отправляется.
Быстрый способ — закладка
  1. Перетащите эту кнопку на панель закладок браузера: 📥 Steam → история чатов
    Панель закладок не видна? Ctrl+Shift+B
  2. Откройте журнал сообщений Steam и войдите в аккаунт.
  3. Нажмите закладку. Она сама загрузит всю историю и скачает файл steam-chat-….html.
  4. Перетащите скачанный файл сюда.
Ручной способ
  1. Откройте страницу help.steampowered.com → Данные аккаунта → Журнал сообщений и войдите в аккаунт.
  2. Прокрутите вниз и нажимайте «Загрузить ещё», пока кнопка не пропадёт (иначе сохранится только часть истории).
  3. Нажмите Ctrl+S → «Веб-страница, только HTML» и сохраните файл.
  4. Перетащите сохранённый файл сюда (можно несколько сразу).
